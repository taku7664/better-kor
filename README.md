# better-kor

한국어로 답하고 쓸 때 쓰는 Claude Code 스킬입니다. 번역투를 걷어내고, 억지 우리말도 억지 음차도 아닌 **그 분야에서 실제로 쓰는 말**로 전달합니다. 모드 인자로 브리핑·문서·이슈·PR처럼 글의 성격을 바꿉니다.

Codex에서도 같은 스킬 파일을 그대로 씁니다.

## 어떤 문제를 푸나

LLM이 쓰는 한국어는 두 방향으로 어긋납니다.

| 어긋나는 방향 | 이렇게 쓴다 | 이렇게 써야 한다 |
|---|---|---|
| 억지로 우리말을 만든다 | 뿌리 노드, 조작 막대 | **루트 노드**, **슬라이더** |
| 아무 말이나 음차한다 | 레이스 컨디션, 데드락 | **경쟁 상태**, **교착 상태** |

판정 기준은 하나입니다. **이 판을 아는 한국 사람이 이걸 입으로 뭐라고 말하나.**

구조도 문제입니다. 결론이 맨 아래 묻히고, 확인한 것과 추측이 섞이고, 확인하지 못한 범위를 밝히지 않습니다.

## 설치하기

1. 저장소를 내려받습니다.

   ```bash
   git clone https://github.com/taku7664/better-kor.git
   ```

2. 스킬 폴더를 Claude Code 쪽에 복사합니다.

   ```bash
   cp -r better-kor/skills/better-kor ~/.claude/skills/
   ```

3. Codex에서도 쓰려면 같은 폴더를 한 군데 더 둡니다.

   ```bash
   cp -r better-kor/skills/better-kor ~/.agents/skills/
   ```

4. 새 세션을 열면 `/better-kor`로 부를 수 있습니다.

## 훅으로 거들기 (선택)

스킬만으로도 돌아갑니다. 매번 부르지 않고 한국어 규칙을 항상 걸고 싶으면 `hooks/`를 씁니다.

1. 훅 스크립트를 복사합니다.

   ```bash
   cp better-kor/hooks/better-kor-pr-issue.js ~/.claude/hooks/
   ```

2. `hooks/settings-snippet.json`의 내용을 `~/.claude/settings.json`에 합칩니다. 스니펫 안의
   `<여기에 홈 경로>`를 실제 경로로 바꿉니다.

| 훅 | 언제 | 무엇 |
|---|---|---|
| 한국어 지침 | 매 턴 | 번역투·존댓말·결론 먼저 |
| PR·이슈 | 그 말이 나왔을 때 | `pr`·`issue` 절 요점 |

저장소 단위로 걸고 싶으면 `AGENTS.md`에 적습니다. 그 저장소에서 도는 Claude와 Codex가 세션
시작할 때 읽습니다.

## 모드 고르기

```text
/better-kor            기본. 번역투 없는 한국어
/better-kor report     기본 + 자료·수치 대조 규율
/better-kor docs       기본 + 마크다운 문서 규격
/better-kor explan     기본 + 쉽게 설명
/better-kor issue      기본 + 이슈 (버그 신고·기능 제안)
/better-kor pr         기본 + PR 본문
```

**기본은 항상 적용되고 모드는 그 위에 얹힙니다.** 인자 없이 부르면 기본만 씁니다.

| 모드 | 무엇을 더하나 |
|---|---|
| (기본) | 말투·상대·분량·용어·번역투. 산출물과 덧붙이는 말의 경계 |
| `report` | 「전부」라고 쓰기 전에 몇 개 중 몇 개를 봤는지 적기, 세는 규칙 먼저 정하기, 인용한 줄을 다시 열어 보기 |
| `docs` | 마크다운 구조. 길게 쓰라는 뜻이 아니라 다시 찾아볼 수 있게 |
| `explan` | 비유 하나와 그 비유가 깨지는 지점. 용어는 그대로 두고 한 번 풀기 |
| `issue` | 검색될 제목, 증상으로 시작, 재현 절차 |
| `pr` | 리뷰어를 읽는 사람으로. 고정 체크리스트 대신 diff에서 뽑아 쓰기 |

## 아직 확인하지 못한 것

- **여섯 모드 중 실제로 검증한 것은 `report` 하나뿐입니다.** 나머지는 규칙을 쓰기만 했습니다.
- 번역투 임계값이 이 스킬의 용도에 맞는지 확인하지 않았습니다.
- Codex에서 실제로 뜨는지 파일 배치만 확인했고 실행해 보지 않았습니다.
- 모드를 더 늘릴지, 지금 여섯으로 고정할지는 미정입니다.
